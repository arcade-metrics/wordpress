# Marca

SVGs com `viewBox` cortado rente ao desenho. O slogan faz parte da imagem, por isso há uma versão por idioma.
Sufixos: `ptbr` (Polylang `pt`, também o fallback), `en-uk` (`en`), `es` (`es`).

| Arquivo | Uso |
|---|---|
| `ciatec-logo-dark.svg` | Logo **sem slogan** (igual em todos os idiomas), texto claro. Header, sempre escuro |
| `ciatec-logo-light.svg` | Logo sem slogan, texto preto. Reserva e JSON-LD |
| `ciatec-logo-dark-<idioma>.svg` | Texto claro, para fundo escuro. Com slogan. Rodapé, no idioma da página |
| `ciatec-logo-light-<idioma>.svg` | Texto preto, para fundo claro. Reserva (impressão, og-image) |
| `ciatec-icon.svg` | Só o anel colorido. Reserva (ex.: avatar, favicon) |
| `favicon.png` | Favicon 512x512 (ignorado se o site tiver ícone definido no WordPress) |
| `og-image.jpg` | Imagem de compartilhamento 1200x630. **Ainda falta** |

Cores da marca: ciano `#01A0C0`, verde `#5C823D`, rosa `#E3569F`, laranja `#F89E26`. Só decorativas (ciano e verde não passam 4,5:1 como texto sobre branco).
